# SkyknightsOnline — Project Summary

**SkyknightsOnline** is an **indie Planetside 2 competitive flight sim** — a sci-fi multiplayer territory-control game where pilots fight over persistent world objectives in armed aircraft. Built in **Godot 4.3**, it sits in the zone between arcade and simulation: a spring-damper flight model with hover-lift, afterburner, and gimbaled first-person cockpits with pitch ladders and heading indicators. The core loop is **pilot → fight → capture → resupply → rearm**, driven by slot/inventory loadout customization (nosegun + pylons) and territorial objectives (Biolab, Tower, domain blocks). The architecture is **autoload-centric** — 11 globally-accessible singletons form a hub-and-spoke system. Ships extend `BaseShip` (a `CharacterBody3D`) with a slot/inventory equipping system; the only implemented ship is the **Marauder**, a swing-wing fighter with two noseguns (Colt, Vortek) and two pylon weapons (Tanks, RocketPods — stubs). A dual-backend networking layer (ENet + WebSocket) with a control-server orchestration model (Planetside-style persistent servers, not lobby matchmaking) is fully coded but **entirely commented out**; the game currently runs single-player only. The Hangar scene provides ship/weapon selection with a rotating pedestal. A persistent settings system with reactive binding and an in-engine parameter editor (EngineEditor) support development and tuning. Blender import scripts (currently disabled) handle material assignment and trimesh collision generation.
