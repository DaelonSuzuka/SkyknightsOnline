# SkyknightsOnline — Project Summary

**SkyknightsOnline** is a sci-fi flight combat MMO built in **Godot 4.3**. The player flies armed ships through 3D environments with a spring-damper flight physics model, equip-based weapon loadouts, and a full HUD (pitch ladder, heading, minimap, strategic map with waypoints, weapon info, engine editor). The architecture is **autoload-centric** — 11 globally-accessible singletons (Game, Player, ShipManager, InputManager, Scenes, Settings, HUD, MainMenu, Stopwatch, Files, Args) form a hub-and-spoke system. Ships extend `BaseShip` (a `CharacterBody3D`) with a slot/inventory equipping system; the only implemented ship is the **Marauder**, a swing-wing fighter with two noseguns (Colt, Vortek) and two pylon weapons (Tanks, RocketPods — stubs). A dual-backend networking layer (ENet + WebSocket) with a control-server orchestration model is fully coded but **entirely commented out**; the game currently runs single-player only. The Hangar scene provides ship/weapon selection with a rotating pedestal. A persistent settings system with reactive binding and an in-engine parameter editor (EngineEditor) support development and customization. Blender import scripts (currently disabled) handle material assignment and trimesh collision generation.
